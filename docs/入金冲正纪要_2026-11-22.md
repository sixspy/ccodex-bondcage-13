# 入金冲正纪要（保证金笼）

- 锁死日期：2026-11-22（当日定案，当日锁死）
- 适用库：`data/app.db`（库路径不变，SQLite 母仓）
- 适用界面：沿用既有会话（同一套登录令牌与八页导航，不新开系统）
- 状态：**已锁死**。任何口径变更须另立新版纪要并显式作废旧版；旧版规则在本版生效期内不可热改。

## 一、事故口径

入金记错金额导致 `bond_accounts.balance` 虚高，后续入笼（`cages` 冻结、`frozen` 累加）均建立在错数之上。
系统无冲正写口，运维只能私下改库——本纪要即为消灭该缺口而设立。冲正必须：

1. 扣回虚高余额；
2. 不影响已冻结部分（`frozen` 与笼内 `available`）的合法性；
3. 留冲正流水与审计，禁止只改账户页红字、禁止页面层遮盖。

## 二、正确性口径（二选一，不得混用）

冲正正确性只允许以下两条路径中的**一条**，同一次冲正内禁止混用，跨请求也禁止双轨并存：

- **甲路径（同一提交回滚口径）**：同一数据库事务内写冲正流水、扣减账户余额、写审计；
  若扣减后账户可用额（`balance - frozen`）为负，则整笔回滚——余额、流水、审计全部不落。
- **乙路径（影子冲正单晋升口径）**：先落影子冲正单，复核后在一个原子事务内写冲正流水并切余额；
  晋升失败则影子作废、余额零改。

### 当日锁死结论

**本仓只启用甲路径（同一提交写冲正流水、扣减账户余额并记审计；扣后可用为负则整笔回滚）。**

- 乙路径不实现、不留半成品接口；请求若携带非甲路径口径（`path_mode != "A_same_txn"`），
  一律记 **冲正偏航（`deposit_reversal_deviation`）** 审计并拒写（HTTP 400），不产生任何业务写。
- 代码中 `reversal_policy.REVERSAL_PATH_LOCKED` 为唯一口径来源；前端只展示，不参与裁决。
- 禁止先影子后转正的任何变体，禁止把一次冲正拆成「先扣余额后补流水」两个事务。

## 三、甲路径执行规则

1. 入口：`POST /api/bonds/deposit/reversal`，写角色（admin/clerk）可用，viewer 拒写。
2. 必须先抢账户锁 `bond:{party_key}`；两人同时冲正同一当事人，后到者抢锁失败：
   只在 `contention_log` 留争用痕并返回 409，**不写任何业务数据**（余额、流水、审计均不动）。
3. 锁内校验（全部在同一事务内、任何业务写之前完成；不过则整笔回滚、零改）：
   - 账户存在且状态为「正常」；
   - 冲正金额 > 0，且不超过该当事人当前可用额（`balance - frozen`），否则 409 整笔回滚——
     这一条保证已冻结部分永远不被误伤；
   - 关联入金流水 `deposit_id` 存在且属于该当事人；
   - 对同一入金流水的累计冲正额不得超过该流水原始入金额，否则 409 整笔回滚。
4. 通过后同一事务内完成三写并单次提交：
   - 写 `deposit_reversals` 冲正流水（含 reversal_ref、deposit_id、金额、操作者、原因、口径标记 A_same_txn）；
   - 在 `deposit_ledger` 写一条负额冲正账（金额为负，memo 挂 reversal_ref），入金账因此可轧平；
   - 扣减 `bond_accounts.balance`（`frozen` 不动）；
   - 写审计 `deposit_reversal`，载荷含口径标记、前后余额、可用额校验值。
5. 偏航（口径不符、试图走影子晋升等）：记 `deposit_reversal_deviation` 审计后拒写，
   偏航请求不产生冲正流水、不改余额。
6. 冲正失败（任何 4xx/回滚）后，账户余额与冲正前完全一致，可安全重试。

## 四、五页同源

账户页、入笼页、对账页、审计页、增补页五页全部只读同一 SQLite 母仓（`data/app.db`），
禁止页面私有数、禁止页面红字直改：

- 账户页：余额/冻结/可用取自 `bond_accounts`，并展示冲正流水（负额入金账 + `deposit_reversals`）；
- 入笼页：笼额与冻结取自 `cages` / `bond_accounts.frozen`，冲正不触碰任何笼字段；
- 对账页：新增账户侧轧平式——入金合计 − 冲正合计 − 冻结 − 已拨付 − 已罚没 == 0；
  笼口径（available + released + forfeited == amount）维持不变；
- 审计页：`deposit_reversal` 与 `deposit_reversal_deviation` 均可查，并可查冲正流水专表；
- 增补页：顶部口径带展示当前锁死路径（来自接口，不允许页面自选乙路径）。

## 五、测试纪律（与纪要同锁）

1. 先造「错入金无法冲正」的假绿事故夹具；
2. 先落冲正无效的失败测（红），再落双人同冲正争用的失败测（红）；
3. 两条失败测均见红之后，才准改账户服务、对账服务、审计服务、入笼服务与账户页；
4. 禁止跳过失败测，禁止无测直线改文案；
5. 改完以夹具在本机文件库跑通：余额回正、冻结不被误伤、五页同源。
